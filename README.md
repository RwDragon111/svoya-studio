# Своя — студия викторин

Русский конструктор «Своей игры» для ведущего, команд и проектора. Полностью статический сайт: HTML, CSS и JavaScript, без сервера и без регистрации.

## Как пользоваться

1. Создайте игру или откройте демонстрационную. Добавьте темы, раунды, вопросы и правильные ответы.
2. При желании добавьте картинки, аудио или видео. Они хранятся в проекте, а не загружаются на сторонний сервер.
3. Настройте названия команд и длительность таймера. Ноль отключает таймер.
4. Нажмите **Скачать проект**. Этот JSON-файл содержит все вопросы, ответы и вложения. Кнопка **Открыть файл** создаёт независимую копию проекта.
5. Для мероприятия нажмите **Провести игру**, затем **Открыть экран зрителей**.
6. Подключите проектор в режиме **расширения рабочего стола**, перенесите на него окно зрителей и нажмите **На весь экран**. При дублировании рабочего стола ответы на пульте будут видны зрителям. В видеозвонке демонстрируйте только окно зрителей.
7. Ведущий выбирает вопросы и начисляет или снимает баллы. Ответ ведущему виден сразу; зрителям — только после отдельной кнопки. Заметки ведущего не передаются в экран зрителей даже при показе ответа.

Оба окна должны работать в одном браузере на одном компьютере. Синхронизация использует BroadcastChannel. Это режим для второго монитора, а не сетевой пульт с телефона.

## Сохранение

Проекты автоматически сохраняются в IndexedDB этого браузера, включая вложения. Счёт, сыгранные вопросы и состояние таймера сохраняются отдельно; игру можно продолжить после перезагрузки. Возобновление использует снимок вопросов на момент начала игры. Новая игра использует текущую версию проекта.

Данные **не синхронизируются с GitHub** и не доступны на других устройствах без экспорта файла. Очистка данных сайта, приватный режим и удаление профиля браузера могут удалить локальные проекты. Перед мероприятием скачайте резервную копию. Сайт не отправляет ваши викторины на сервер; публичный репозиторий содержит только код и демонстрационные вопросы.

Лимиты: до 12 раундов, 10 тем и 10 вопросов на тему в каждом раунде, 12 команд; изображения до 8 МБ, аудио/видео до 25 МБ, проект до 80 МБ. SVG и произвольные внешние ссылки на медиа не поддерживаются. Поддержка воспроизведения конкретных аудио/видеокодеков зависит от браузера; для видео предпочтителен MP4 с H.264/AAC. Медиа запускаются в окне зрителей вручную, чтобы браузер не блокировал звук.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `svoya-studio` и загрузите файлы из этого каталога в ветку `main`.
2. Откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, ветку **main**, каталог **/(root)** и нажмите **Save**.
4. Дождитесь успешного развёртывания `pages build and deployment`. Ссылку GitHub покажет в Settings → Pages.

Все пути относительные: приложение работает как в корне домена, так и в подпапке GitHub Pages. `.nojekyll` отключает обработку Jekyll. Сборка и платные сервисы не нужны.

## Проверки

Для тестов требуется Node.js 22.22.2+, 24.15.0+ или 26+. Проверено на Node.js 24.19.0.

```sh
npm ci
npm run check
npm test
```

Dev-зависимости используются только в тестах. Они не загружаются сайтом. Интеграционный тест в jsdom проверяет создание и автосохранение проекта, загрузку вложения, экспорт/импорт, два окна с обменом сообщениями, сокрытие/показ ответа, счёт, таймер и восстановление игры из IndexedDB. Это проверка DOM и логики, не замена визуальному тесту в реальном браузере с проектором.

Для локального запуска используйте любой HTTP-сервер, например `python3 -m http.server 8080` из каталога проекта, и откройте `http://localhost:8080`. Двойной клик по `index.html` не подходит для ES-модулей и надёжной синхронизации окон.
